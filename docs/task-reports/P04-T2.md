The implementation adds bounded strict structured-output extraction, exact chunk-evidence validation, conservative confirmed-alias matching, durable versioned work/results/status, ready-event/recovery dispatch, and evidence-backed noncommitting entity/relationship/derived-field publication. Underlying document read/search stays available when extraction is blocked or fails.

Execution holds the actual source row lock, then the document row lock, and revalidates the current ready document version before input read/send. That transaction and exact source/document fence stay held through bounded provider attempts and publication. Each attempt rereads current AI settings and rechecks the current version; final publication checks the active unexpired work lease and commits replay after graph writes. Work remains bound to its captured source generation; duplicated ready events or recovery never rebind stale work.

Permanent `local_only_source`, unavailable document/source-generation, invalid-reference and input-limit blocks do not receive timer retries. `ai_policy_denied` and `structured_unsupported` are recoverable only when a durable SHA-256 over nonsecret settings, model mapping and the exact capability-cache identity/validated result/check/expiry snapshot changes, and current policy plus a fresh supported capability allow sending. Recovery is bounded, does not probe the provider, does not increment attempts while inspecting, and defers unchanged/denied rows. An accepted dependency transition reuses the same work identity/captured generation and resets its finite attempt cycle.

External provider identity and owner correction/redirect matching remain unavailable until their authoritative identity/correction storage and consumer exist. P04-T2 matches only confirmed aliases; name similarity creates review candidates. P04-T3 owns persistent owner corrections.

## Independent review repairs (F1–F6)

- **F1:** `description` is a required nullable extraction field, and entity/relationship confidence validators reject booleans and strings before coercion, then enforce finite `[0, 1]` values.
- **F2:** document chunk/current-version/source-generation evidence validation belongs to the documents owner and returns detached `ExtractionEvidenceRef` DTOs. Entity membership publication accepts the DTO and no longer reads document persistence models.
- **F3:** derived relationship reuse is restricted to unbounded current-state edges; evidence retries preserve maximum per-citation confidence and recompute edge confidence from supporting evidence.
- **F4:** entity resolution is staged before publication, matched entities are locked in stable order, and candidate snapshots are refreshed under those locks. Changed or incomplete outcomes become review-only. Recovery fetches bounded pages without retaining source locks, then rechecks and commits each ready or blocked work item in its own transaction.
- **F5:** mutable policy/capability blocks are inspected regardless of the previous attempt count and rearm only after a changed dependency fingerprint plus current eligibility; rearming resets the attempt cycle. Exhausted expired running leases are terminalized in bounded batches, and claim terminalizes exhausted work before honoring a future retry timestamp.
- **F6:** candidate rows use a compact projection and aliases are queried only for names in the current candidate batch, with independent bounded lookahead. Overflow makes every candidate of the affected type review-only, including the post-lock refresh.
