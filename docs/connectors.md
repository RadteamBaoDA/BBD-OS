# Packaged connectors

Connector routes use `/api/v1/connectors/sources/{source_id}`. The owner creates a source and configures it with `PUT /configuration`, then issues a source-scoped collector token through `POST /api/v1/ingestion/sources/{source_id}/collector-credential`. Keep that token in an n8n Header Auth credential; do not put provider secrets in BBD-OS source configuration. Collector access is revoked automatically when the source is paused or archived.

Configure RSS/Atom sources with `{"feed_url":"https://example.org/feed.xml"}`, web sources with `{"url":"https://example.org/","js_render":false}`, and REST sources with a URL plus `items_path`, `id_field`, `title_field`, `content_field`, and optional `updated_field`. Configuration rejects unknown fields, non-public hosts and invalid IANA timezones. New and unconfigured sources use `Asia/Ho_Chi_Minh`. RSS/Atom reads at most 10 pages, catches up from the last accepted cursor with a one-day overlap, caps aggregate response data at 25 MiB, and fetches through the isolated browser service with its shared 60-second job limit. Provider credentials belong in n8n credentials.

Import the inactive workflow exports from `infrastructure/n8n/workflows/`. Set `BBD_SOURCE_ID` in the n8n container, map the imported “BBD-OS source collector” reference to the source token, configure the REST credential reference when using REST, set the workflow timezone to match the source, then activate the schedule. Runs coalesce missed ticks by reading from the last accepted cursor. A successful `POST /sync` receipt advances the source cursor and returns the durable ingestion `run_id`.

Run `docker compose -f docker-compose.yml -f docker-compose.connectors.yml up -d --build` so API, n8n and the isolated browser service share the same Compose project/network. Set `BROWSER_SHARED_TOKEN` to the same random value for the API and browser container. The browser service accepts only authenticated API requests, allows one active job, and uses Crawlee’s BeautifulSoup HTTP crawler by default or Playwright when `js_render` is enabled. Defaults and hard maxima are 10 pages, depth 2, 60 seconds, and 25 MiB per job. URLs, DNS answers, redirects and browser subresources are checked; the browser container firewall denies private/reserved egress and permits public HTTP(S) plus DNS. Collection never performs model-driven navigation.

Pause and resume a source through the existing owner-authenticated `PATCH /api/v1/sources/{source_id}` status field. Paused/archived sources cannot validate, submit batches or crawl. Workflow exports are templates: imported credential references must be mapped in the local n8n instance before activation.
